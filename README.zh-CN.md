一款轻量的开发者工具箱，基于 Rust 与 GPUI 构建的桌面应用。

## 功能特性

内置 10 个常用开发工具：

- **哈希计算**：MD5 / SHA1 / SHA256 / SHA512 / SHA3-256 / SHA3-512 / BLAKE3
- **密码哈希**：Argon2 生成
- **二维码生成**：可调纠错等级
- **时间戳转换**：秒 / 毫秒，支持 24+ 时区
- **URL 编解码**
- **进制转换**：二进制 / 八进制 / 十进制 / 十六进制
- **UUID 生成**：v4 / v7，批量生成，样式选择
- **Base64 编解码**：标准 / URL 安全字母表，可选填充
- **颜色转换**：HEX / RGBA / ARGB Hex / HSLA，支持透明度
- **命名风格转换**：camelCase / snake_case 等 8 种命名风格
